# booksafe-support — abgelöst / superseded

Diese GitHub-Pages-Seite war die Support- und Datenschutzseite der BookSafe-Versionen
bis 0.9. Seit dem 1.0-Release (06.08.2026) leitet sie nur noch auf die aktuelle Seite um:

**https://booksafe.app/support/** (EN: https://booksafe.app/en/support/)

Das Repo bleibt bestehen, weil die Store-Metadaten älterer Versionen auf diese URL
zeigen. Inhaltliche Pflege findet ausschließlich im Landingpage-Repo statt.
